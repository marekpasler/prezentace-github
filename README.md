# GitHub & GitHub Pages – prezentace

Prezentace na seminář programování (15–20 min). Sama běží na GitHub Pages: https://marekpasler.github.io/prezentace-github/

- Ovládání: → / mezerník / klik / klikátko (PageDown) = další krok, ← = zpět, F = celá obrazovka, D = záznam dema (D nebo Esc zpět), B nebo . = černá obrazovka, H = nápověda.
- Na PC s vypnutými animacemi ve Windows otevři adresu s `?motion`, jinak deck běží bez animací.
- Data (`data/`) jsou snímek skutečného `git log` plesového webu: `node tools/extract-data.mjs ../plesoktava`
- Offline: celá složka funguje bez internetu (GSAP i písma jsou ve `vendor/`). Otevři přes lokální server, např. `npx http-server .`
- Záložní video dema ulož jako `assets/demo.mp4`.
